# 冲锋号活动检索

天津&河北冲锋号查询一览。纯 HTML、CSS、JavaScript 静态网站，无需数据库或构建步骤。

## 功能

- 按关键词、参与平台（小红书 / 抖音 / 视频号）、内容形式和报名状态检索。
- 查看活动时间、参与条件、奖励规则、报名文档及原始海报。
- 适配手机与电脑；报名状态依据北京时间判断。

当前收录大黄蜂17号、蛮好的人生直播、爱心守护神2.0、暖医保、超级玛丽17号五项活动。规则来自提供的海报，文档入口未核验；不自动同步外部资料。

## 发布到 GitHub Pages

1. 在自己的 GitHub 账号下新建公开仓库，例如 `chongfeng-activities`。
2. 将本项目全部文件上传，将 index.html 放在仓库根目录。
3. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`。
4. 选择 `main` 分支和 `/(root)` 目录，点击 Save。
5. 等待 Pages 完成发布，在该设置页获取实际网址。

以后在同一个仓库更新 仓库根目录 内的文件即可更新网站；不更改仓库名、账号名及 Pages 配置时，可保持原访问地址。GitHub Pages 的国内网络可达性需实际测试。

## 本地查看

直接用浏览器打开 `index.html`，或使用任意静态 HTTP 服务指向 仓库根目录。

## 更新活动

数据在 `app.js` 顶部的 `activities` 数组。修改标题、平台、日期、资格、奖励表格与报名入口后提交即可。增加或删除活动时，同步修改 `index.html` 中的活动总数及录入日期。新增海报放在 仓库根目录，使用相对路径引用。

分享描述在 `index.html` 的 description / Open Graph / Twitter 标签中；图片为 `og.png`。取得正式 Pages 地址后，分享图片元数据应改为该站点的完整绝对 URL。微信不保证采用通用网页分享元数据。

## 目录

- `index.html`：页面结构及分享信息
- `style.css`：样式
- `app.js`：活动资料、筛选与详情
- `*.png`：活动海报及分享图
- `LICENSE`：原创代码的 MIT 许可证
- `NOTICE.md`：第三方资料说明
