# 冲锋号活动中心

访问 https://silver1530.github.io/chongfeng-activities/ 。

前端为静态 HTML/CSS/JavaScript，活动数据实时读取 https://82.156.166.113/api/activities ，海报从同一服务器加载。后台确认发布后，刷新此网址即可获取最新活动，无需再修改 GitHub 文件。

后台管理通过服务器的独立认证入口访问，本仓库不包含管理员密码、私钥或后台程序。GitHub Pages 不提供后端服务；当活动服务器不可用时，会显示加载失败和备用入口，不使用可能过期的静态数据冒充最新数据。

所有活动统一展示，不按天津/河北筛选。活动原始奖励分组和参与条件仍按主办方资料展示。
